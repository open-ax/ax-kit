<h1 align="center">ax-kit</h1>

<p align="center">The web was built for human eyes. We're building it for agents.</p>

---

Today most AI agents use the web by taking screenshots and guessing where to click.
It works, but it's slow, brittle, and burns tokens fast.

`ax-kit` is the other way around. A website tells an agent what it can do, and the
agent just does it. Less guesswork, less waiting, less spend.

Open source, built in the open, following the
[WebMCP](https://webmachinelearning.github.io/webmcp/) draft from the
[W3C Web Machine Learning Community Group](https://www.w3.org/community/webmachinelearning/)
on giving agents a first-class way to use the web. Pinned draft: 2026-09-29,
exported as `SPEC_VERSION` from `@ax-kit/core`.
